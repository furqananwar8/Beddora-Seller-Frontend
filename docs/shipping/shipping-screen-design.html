Shipping: Create Shipment & Bookings — screen design

Beddora · draft for review · Oct 2026
Book parcels through Stallion, Shippo and UniUni from one screen
Staff pick one of our products, the form fills itself from the product master, anything missing is flagged in red, then rates from every provider stream in side by side. One rate is selected and booked; the label is printed in the size the user chooses. Every booking from every provider lands on one Bookings list.

Flow

1 · Address Info
Ship-from (saved addresses), ship-to, address check
→
2 · Shipment Info
Product picker, carton L×W×H + weight, customs lines (HS, origin), duties DDP/DAP/DDU, pickup / drop-off
→
3 · Rates
Streamed live (SSE) from all providers, sort by Total price / Delivery time, select one
→
4 · Booking
Review, label size, book, print label / commercial invoice
→
Bookings list
Search, provider, status, date range + Apply; print, track, cancel

Rules the screens follow

• Required fields the product doesn't supply get a red border + message; "Get rates" stays disabled until they're filled.
• Prefilled values are editable (grey fill shows "from product").
• Back keeps everything entered; changing step 1–2 data clears stale rates.
• One rate selectable at a time.

Backend it maps to

POST /shipping/rates (SSE stream)
POST /shipping/shipments (+ Idempotency-Key)
GET /shipping/shipments
GET /shipping/shipments/:id/documents/:type?format=
POST /shipping/shipments/:id/cancel
GET /shipping/shipments/:id/tracking
GET /shipping/config
Provider marks on these mockups are placeholders (coloured initials); the build uses each provider's logo asset. All data shown is sample data.
